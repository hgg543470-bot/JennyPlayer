# Разбиение ui_v71.js и ui_help.js на модули

Инструменты, которыми `ui_v71.js` и `ui_help.js` (коммит `9ae6639`) разрезаны на тематические файлы
`ui_*.js` (18 и 12 штук), и проверки, что порядок патчей при этом не изменился.
Общий замысел и риски — в `REFACTOR_PLAN.md` в корне.

Запуск (нужен Node 18+):

    cd tools/split_v71
    npm install          # ставит парсер acorn
    bash run_all.sh      # берёт исходники из git, режет оба файла, проверяет

Результат появляется в `out_ui_v71/` и `out_ui_help/`. Если проверки чистые, файлы копируются в
`app/src/main/python/`, а списки из `_manifest.json` должны совпадать со списками
`JENNY_UI_V71_PARTS` и `JENNY_UI_HELP_PARTS` в `player.py`.

Раскладка `ui_v71.js` считается автоматически (`themes.js`, `overrides.json`).
Раскладка `ui_help.js` задана вручную по номерам блоков в `overrides.ui_help.json`.

| Файл | Что делает |
|---|---|
| `an2.js` | Разбирает все JS-файлы: блоки, что читается и пишется при загрузке, таймеры, обработчики, стили |
| `units.js` | Делит `ui_v71.js` на неделимые блоки и собирает ограничения порядка |
| `themes.js`, `overrides.json` | Правила, по которым блок относится к теме; ручные поправки и порядок файлов |
| `partition.js` | Раскладывает блоки по файлам так, чтобы ограничения порядка выполнялись |
| `split.js` | Пишет файлы: переносит блоки без правок, патчи-замыкания режет на куски |
| `verify.js` | Сверяет старый и новый вариант: порядок определений каждого имени, обработчиков, стилей |
| `complete.js` | Проверяет, что ни один блок не потерян |
| `dyn.js` | Загружает старый и новый набор в Node с заглушкой браузера и сравнивает итог |
| `dups.js`, `final.js`, `gen.js` | Таблицы для `REFACTOR_PLAN.md`: повторные определения, раскладка, куски патчей |

Чтобы переложить блок в другую тему, добавьте диапазон строк в `overrides.json` (`ranges`) и снова
запустите `run_all.sh`. Если проверки не проходят, раскладку применять нельзя.
