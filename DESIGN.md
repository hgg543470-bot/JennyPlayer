# Jenny's Player: как задумано. Читать перед работой
Суть: живой звук, любая скорость, реверс, питч-лок. Видео умеет то же.
Архитектура JS+Python+Java+Go+C++ сложная специально. Это не мусор.
Видео декодируется в RAM ради реверса.
Немой тег = якорь шторки, только витрина. Звук идёт через эффекты.
Реверс: разворот с текущей позиции. Дошёл до 0 = предыдущий трек с конца.
v36ir и v40ir = модули поиска, исходников нет. Не удалять.
omnitorrent.so arm64 не собирается из .go, пока .so лежит в репо.
xflac, vcore, hose_dsp собираются из исходников при сборке.
